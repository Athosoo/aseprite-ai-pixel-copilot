# AI Pixel Copilot · UI v1.0（工作台）

> 状态：**规格已冻结**。配套 `docs/arch-v1.0.md`。所有像素值都是 Aseprite Dialog 内坐标，
> 不是 DPI 缩放后的值。渲染只能在 `dlg:canvas` 的 `GraphicsContext` 上自绘 ——
> 可用原语只有 `fillRect / fillText / measureText / drawImage`，
> 可用控件只有 `button / label / entry / canvas / combobox / separator`。

---

## 1. 设计立场

**一句话**：这不是一个聊天框，是一张**制图台**（drafting table）。

像素画的作者在 Aseprite 里面对的是网格、色板、图层面板；一个圆角气泡、投影、
渐变按钮的聊天窗口，是在他的工作台上贴了一张外卖单。所以：

1. **直角。无阴影。发丝线。** 1px 边框 + 4px 基准栅格。结构靠**线**和**留白**表达，不靠填充色块。
2. **数字用等宽对齐。** 像素数、颜色值、耗时、版本号 —— 全部右侧对齐成列。这是工具与玩具的分界。
3. **强调色来自你的画。** 工作台的 accent 从当前 sprite 的调色板里取**彩度最高**的颜色派生
   （没有调色板则退回品牌蓝）。于是工具永远和它在编辑的那张图是同一种气质，且随图而变。
4. **终端不消失，它降级成一台。** 老用户的 `menu` / 命令表 / 回显全部保留 —— 
   终端是主视图里的 **Console** 页，而不是整个应用。
5. **状态永远可见。** 断连、思考中、待确认、被中断 —— 四个状态各有固定位置和固定颜色，
   不弹模态、不遮挡画布。

```
├──────┴─────────────────────────────────────────────────┴──────────────┤

└───────────────────────────────────────────────────────────────────────┘
```

- 默认窗口 **900 × 620**，最小 **640 × 420**。
- **左轨 56px**：能力导航，每项 = 图标 + 焦点底纹。当前视图顶部有一条 2px accent 竖条。
- **右上下文 240px**：可折叠（点 titlebar 的 ◫，或 `Alt+C`）。折叠后主视图吃掉宽度，
  上下文的关键三行（文档/待办/状态）压成 composer 上方的一行窄条。
- **主视图**：占用剩余宽度；内部自带标题行（视图名 + 视图内动作，右对齐）。
- **composer 40px**：恒在底部。会话进行中左侧 ▶ 变成转圈点，右侧 ⏹ 从灰变可点。
- 窗口宽 < 760 时：右上下文自动折叠；< 700 时左轨从「图标 + 文字」退化为纯图标（它本就是纯图标）。

## 3. 设计令牌

### 3.1 颜色（深色为主，浅色同构）
| token | 深色 | 用途 |
|---|---|---|
| `bg` | #111318 | 主背景 |
| `surface` | #171a20 | 面板/视图底 |
| `surface2` | #1d2129 | 悬浮行、当前行 |
| `line` | #2a2f39 | 发丝线 |
| `lineHi` | #3a414e | 焦点边框 |
| `text` | #dfe3ea | 主文字 |
| `dim` | #79818f | 次要文字 |
| `faint` | #4d5461 | 禁用/占位 |
| `accent` | 由调色板派生，缺省 #6ea8fe | 焦点、当前视图、进度 |
| `ok` | #5ec98a | 成功、已连接 |
| `warn` | #e0b34a | 待确认、降级 |
| `err` | #e2657a | 错误、断连 |
| `busy` | #7f9cf5 | 思考中 |

浅色主题只换 `bg/surface/surface2/text/dim/faint/line`，语义色微调亮度，accent 不变。

### 3.2 排版
- 基准字号 **10px**，行高 **14px**。
- **字重规则（v1.1 订正）**：Aseprite 的 GraphicsContext 没有字重，半粗只能用「偏移 1px 双次绘制」模拟 ——
  但这招**只对纯 ASCII 有效**。像素中文字形笔画密集，偏移 1px 再画一遍会把字糊成一团（真机实测：
  「加强明暗对比」「历史」等标题目不忍睹）。所以：**纯 ASCII 才做双次绘制；含非 ASCII 的一律单次绘制**，
  靠 tone（accent / text / dim）表达层级，不靠假粗。这条是 v1.1 修正，v1.0 里写的「标题一律假粗」是错的。
- 数值/ID/耗时一律**等宽语义**：按 `measureText` 预测量每列最大宽，右对齐成列。
- 中文优先用已装 pixel CJK 字体（方舟 10px），缺字回落默认字体；**缺字检测**：关键标签若
  `measureText` 返回 0，退回英文文案（i18n 已有 fallback 机制）。

### 3.3 栅格
间距只有四档：**4 / 8 / 12 / 16**。行高 14，行间距 4 → 列表单行占 18px。
内边距：视图 12；面板 8；按钮 4×8。

## 4. 组件（kit 提供的原语组合）

| 组件 | 组成 | 说明 |
|---|---|---|
| `Row` | text + tone + 可选 badge | 列表基本行，18px 高，悬浮 `surface2`，选中左侧 2px accent |
| `Field` | label(dim, 左) + value(text, 右对齐) | 键值行，用于上下文栏 |
| `Badge` | 4×8 内边距 + 1px 边框 + tone 文字 | 计数、状态、快捷键提示 |
| `Button` | 1px line 边框，hover 反色，@focus` 时边框 `lineHi` + 底 `surface2` | 不收 ENTER（ENTER 归 composer） |
| `Tab` | 视图标题行里的文字页签 | 当前页底部 2px accent |
| `Msg` | 时间(dim 等宽) + 方向符 + 正文（可多行） | 方向符 ▸用户 / ◂AI / ·工具 / !错误 |
| `Divider` | 1px `line` 全宽 | 分隔区块 |
| `Spinner` | 三帧 `·○◎` 轮换，只在 busy 时跑 | 放 titlebar 与 composer |

`▤` 会话 · `◎` 画布 · `◈` 风格 · `✦` 记忆 · `⬡` 扩展 · `⊕` 新建 ·
`⏹` 停止 · `📎` 附件 · `↺` 回滚 · `◂` `▸` 方向。

## 5. 视图清单（v1 必须交付前 3 个，其余为 builtin 包的骨架）

| id | 图标 | 名字 | 内容 | 交付 |
|---|---|---|---|---|
| `console` | ▤ | 会话 | 消息流 + 内联工具结果 + 待确认卡片 + 会话切换/新建/改名 | **v1 必须** |
| `canvas` | ◎ | 画布 | 算子台：算子列表（来自 registry，动态）+ 参数表单 + 预览 + 一步撤销历史 | **v1 必须** |
| `packs` | ⬡ | 扩展 | 能力包管理：已装/启用/健康度/失败原因 + 「让 AI 改进」按钮 + 回滚 | **v1 必须** |
| `styles` | ◈ | 风格 | 风格卡：调色板色块条 + 图层结构 + 规矩摘要；切换/新建 | v1 骨架 |
| `memory` | ✦ | 记忆 | 记忆条目 + 检索框 + 标签云 | v1 骨架 |
| `gallery` | ▦ | 画廊 | 会话产出物缩略图网格（drawImage） | v1 骨架 |
| `settings` | ⚙ | 设置 | 端点/密钥/模型/温度/超时/语言/主题 | v1 骨架 |

**空状态**是设计的一部分，不是「暂无数据」四个字：
- 会话空 → 「说一句你想改的。比如「把这层的红色换深一点」」+ 三个可点的示例。
- 扩展空 → 「还没有自建能力包。让 AI 看看 gaps.md，它知道自己缺什么。」+ 「让它提议」按钮。
- 断连 → 顶部红条：原因 + 一条可复制的起桥命令 + 「重试」按钮。

## 6. 交互模型

**键盘**（全局，无输入焦点时生效）
| 键 | 动作 |
|---|---|
| `/` | 聚焦 composer（并插入 `/` 唤起命令补全） |
| `Ctrl+K` | 命令面板（升级版命令表：模糊搜索所有 registry.command） |
| `Alt+1..6` | 切视图（对应左轨顺序） |
| `Alt+C` | 折叠/展开右上下文 |
| `Esc` | 依次：关补全 → 关弹层 → 中断当前轮（带确认 Badge，2 秒内再按一次才真中断） |
| `↑ / ↓` | 视图内列表导航；composer 历史 |
| `Enter` | composer 提交（**磁吸按钮**技巧见 README 约束 5） |
| `Shift+Enter` | composer 换行（@dlg:entry` 单行，用多行缓冲 + 视觉折行） |
| `Tab` | 焦点在 左轨 → 主视图 → 上下文 → composer 之间轮转 |

**鼠标**：悬浮行变 `surface2` + 光标变手型；点击 = 激活；滚轮 = 视图内滚动；
左轨拖动可重排（v1 不做，留 order 字段）。

**焦点可见性**：任何时刻焦点区左侧有 2px accent 竖条。这是靠键盘能用的唯一凭证。

## 7. 渲染策略（D5 延迟优先）

- **脏区分级**：`rail` / `context` / `main` / `composer` / `titlebar` 五个区域各自独立的
  `dirty` 标记；只有被标记的区域重画。滚动、输入回显、转圈只脏 `main` 或 `composer`。
- **纹理缓存**：字体测量结果按 `(text, style)` 缓存；行按 `(text, tone, width)` 缓存布局矩形。
  缓存上限 2000 条，LRU。
- **禁止整屏重绘**：`Kit` 在 `begin()` 时记下 `invalidate` 集合，`end()` 时统一 `flush`。
- **预算**（写进 bench，超预算即失败）：
  | 指标 | 上限 |
  |---|---|
  | 面板首屏（构建 + 一帧） | < 150 ms |
  | 单次输入回显（键盘→重绘） | < 30 ms |
  | 滚动一屏 | < 16 ms |
  | 900×620 全屏重绘 | < 8 ms |
  | 每次 ui tick 的 Lua 分配 | < 64 KB |

## 8. 与旧实现的关系（D4 全兼容）

- `panel.lua` 的**console 渲染、命令表、回显颜色、i18n 键**全部平移为 `views/console.lua`，
  逐字保留（不改文案、不改配色语义）。
- 四种形态（面板 / 底边栏 / 侧边栏 / 小窗）**全部保留**；工作台是「面板」形态的新实现，
  底边栏 = 隐藏左轨与上下文 + 主视图压成单行；小窗沿用 `miniwindow.lua` 不动。
- 快捷键 `Ctrl+Shift+A / +M / +P` 不变；`/bar` 命令仍能在四形态间循环。
- 主题：沿用当前深色；accent 派生是**新增**行为，取不到调色板时行为与旧版一致。

## 9. 验收

1. **golden layout**：给定 900×620 / 640×420 两个尺寸与固定内容，`Kit` 输出的绘制调用序列
   与基准快照逐条相等（不依赖字体渲染差异，只比 rect 与调用名）。
2. **GUI 截图**：三张 —— 会话页（有真实工具调用）、扩展页（有一个失败包标红）、断连态。
   用 `tests/shot_window.ps1`（PrintWindow 不抢前台）。
3. **bench**：第 7 节五项指标全部达标，输出 JSON 报告到 `tests/bench/report.json`。
4. **可达性**：纯键盘完成「发一句话 → 等回 → 切到扩展页 → 禁用某包」全流程，不碰鼠标。
