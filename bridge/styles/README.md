# 风格包（built-in styles）

这个目录用来**覆盖或补充**代码里内置的风格（`bridge/src/styles.mjs` 的 `BUILTIN`）。

放一个 `<名字>.json` 进来，重启桥就生效。同名会覆盖内置的那个。
**用户的 `bridge/data/styles/` 优先级更高**，所以你自己改过的版本不会被这里盖掉。

优先级：`data/styles/`（用户） > `styles/`（本目录） > 代码内置。

## 格式

```json
{
  "name": "my-style",
  "label": "我的风格",
  "size": [16, 16],
  "palette": ["#1B1B1B", "#2E86DE", "#7EE2A8", "#F5F5F5"],
  "layers": ["主体", "高光", "轮廓"],
  "rules": [
    "轮廓固定 1px，用调色板里最深的颜色",
    "光源在左上：高光偏左上，暗部在右下"
  ],
  "notes": "适合物品/道具/技能图标。"
}
```

| 字段 | 说明 |
|---|---|
| `name` | 风格 id。不写就用文件名。只允许字母/数字/连字符/下划线/中文 |
| `label` | 显示给人看的名字 |
| `size` | `[宽, 高]`，AI 建画布时的推荐尺寸 |
| `palette` | `#RRGGBB` 数组。**只认 6 位十六进制**，格式不对的会被丢掉 |
| `layers` | 图层名，**从下到上**。AI 会按这个顺序分趟作画 |
| `rules` | 作画规矩，一行一条，最多 12 条 |
| `notes` | 补充说明，最多 300 字符 |

## 省 token 的约定

切换风格时，**只有当前那一个**会被渲染进提示词（`describe()`，约 280 字符）。
所以风格数量不影响每次请求的开销，可以随便加。

但也因为它是常驻提示词的一部分，**`rules` 和 `notes` 别写长**——它们每一轮都在花 token。
写"轮廓 1px 用最深色"这种能直接照做的短句，别写散文。

## 三个内置风格

| 名字 | 尺寸 | 特点 |
|---|---|---|
| `pixel-icon` | 16×16 | 硬像素、1px 轮廓、左上光源，适合图标 |
| `stardew` | 16×32 | 暖棕土黄、深棕轮廓、柔和阴影，适合角色/作物/建筑 |
| `flat-minimal` | 32×32 | 无轮廓、几何形状、最多 3 色，适合 UI 图标 |

想改内置的，**不要改这里**——复制到 `bridge/data/styles/<同名>.json` 再改，
这样升级时不会和仓库里的版本打架。
